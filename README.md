# Money Meta

Money Meta превращает внутриигровые экономики в понятные решения: что купить следующим, как быстро окупится актив и какой результат можно получить при ограниченном времени.

Опубликована версия `v1.32`. В разработке `v1.33`; состояние проверок и публикации находится в `docs/CURRENT_STATUS.md`. Платформа работает на русском и английском языках и поддерживает шесть игровых экономик: GTA Online, Dota 2, World of Warcraft Retail, Total War: Warhammer III, Crusader Kings III и Civilization VII.

## Что уже работает

- GTA: сравнение бизнесов, планирование доступных полных активностей на сеанс и недельный журнал прогноза и результата.
- Dota: загрузка публичного матча, проверка экономических эпизодов, контекст составов, хронология покупок, сравнение предметов, окупаемость Midas и резерв на выкуп.
- WoW: затраты на крафт, прибыль и доступные деньги, размер партии с учётом резерва, журнал продаж и оценка фарма.
- Total War и CK3: последствия новых обязательств, отсрочки и изменения дохода для бюджета и защищённого резерва.
- Civilization VII: сравнение двух построек по накопленному выпуску выбранного ресурса и срокам завершения. Правила Civilization VI сюда не переносятся.
- Именованные расчёты, сравнение сохранённых вариантов, заметка о результате и восстановление исходных данных на устройстве.
- Библиотека разборов с поиском и фильтрами, отдельные игровые порталы, карты экономики, сценарии и источники.
- Отдельные досье GTA VI и Fable с подтверждёнными сведениями и явно обозначенными неизвестными.
- Статусы проверки и актуальности данных, полные RU/EN-маршруты, адаптивный интерфейс и автоматические проверки расчётов.

Модели показывают условные последствия введённых данных. Экономический разрыв в Dota не доказывает ошибку игрока; предполагаемые продажи WoW не являются прогнозом рынка. Подробные границы моделей описаны рядом с инструментами и в документации.

## Локальный запуск

Нужен Node.js 22.

```bash
npm install
npm run dev
```

После запуска открыть `http://localhost:4321`.

Проверка перед публикацией:

```bash
npm test
npm run build
npm run audit:site
```

## Где менять данные

Все GTA-бизнесы и provenance находятся в `src/data/gta-businesses.ts`, Dota patch context — в `src/data/dota-economy.ts`, WoW market context — в `src/data/wow-economy.ts`. Формулы и decision logic находятся в `src/lib/`. Не дублируй числа внутри страниц: интерфейс должен получать их из единого набора данных.

Перед переводом статуса числа в `verified` нужно повторить проверку в игре и зафиксировать дату, версию и источник.
